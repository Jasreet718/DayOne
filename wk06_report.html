The goal

Load 100 raw case records, keep every row that can be loaded, set aside the damaged ones with a reason, and never crash. The two piles must add up to 100.

The three traps in the data

1. Truncated rows 6 rows

Some rows have 6 fields instead of 8. parse_row checks len(row) != 8 first and raises a ValueError, so reaching for row[7] never causes an IndexError.

2. Age is 'unknown' 3 rows

int(row[3]) raises ValueError by itself. No extra check needed. It's caught in load_cases.

3. Empty date 2 rows

An empty string doesn't crash anything, so the code checks row[4].strip() == "" itself and raises ValueError("missing date").

How it works

parse_row(row)

One CSV row in, one clean dictionary out. It strips spaces, title-cases names and addresses, upper-cases sex and status, and converts age to an int. If the row is damaged it raises instead of returning.

load_cases(path)

Reads the file with csv.reader, which keeps quoted names like "KIRKLAND, MONICA, JR, III" in one piece. It skips the header with next() and blank lines with continue, and wraps each parse_row call in try / except ValueError. It returns two lists: good and quarantine.

try:
    good.append(parse_row(row))
except ValueError as err:
    quarantine.append((line_num, str(err)))
